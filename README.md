### What I work on

Backend developer at **Yapıdrom Teknoloji**, on a scooter-sharing platform built as 40+ backend
services behind an API gateway, communicating over RabbitMQ and running on Kubernetes.

Two of those services are mine end to end:

- a **multilingual content service** — announcements, FAQ, key-based static content and reference
  data, served to mobile and web clients
- a **feedback & support service** — two-way ratings, ticketing, contextual help and emergency
  notification across every vertical of the platform

The second one began as my internship project. It went to production after the internship ended, and
I still develop it today.

Day to day that means REST APIs in .NET 8/9 with Clean Architecture, PostgreSQL with Entity Framework
Core, Redis for caching, RabbitMQ for asynchronous messaging — and the shared API, error-handling and
observability standards that keep those services consistent with one another.

### Selected work

**[ASTronaut](https://github.com/bqrayvzdgn/ASTronaut)** — `C#` · `TypeScript` · `Roslyn` · `OpenAPI`

Generates OpenAPI 3.1 specifications from .NET source code using Roslyn static analysis, without
running the application — so it works in CI and on code that does not build. A language-agnostic
intermediate representation sits between the parsers and the generator, so other frameworks can be
added without touching the emitter.

Currently building, still private: a WireGuard VPN client for the command line (Go), a cross-platform
terminal emulator (TypeScript), and an all-in-one developer tools desktop app on Tauri.
